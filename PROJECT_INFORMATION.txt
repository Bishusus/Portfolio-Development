2. EXECUTIVE SUMMARY
--------------------
DevEngine is a modern AI-powered portfolio builder platform designed specifically for developers. The platform enables users to create professional, visually appealing portfolios using pre-designed templates across multiple industries (aviation, legal services, business operations). 

Key features include:
- AI-assisted content generation for project descriptions
- Multiple professional portfolio templates with distinct visual designs
- Real-time portfolio preview and editing capabilities
- CSV and PDF export functionality with template-specific formatting
- GitHub profile integration for automatic data import
- Supabase-powered authentication and data storage
- Responsive design with dark/light theme support

The platform streamlines the portfolio creation process, allowing developers to showcase their skills, experience, and projects in a professional manner without requiring extensive design knowledge.

3. TECHNOLOGIES AND TOOLS USED
-------------------------------
Frontend:
- HTML5, CSS3, JavaScript (ES6+)
- Responsive web design with CSS Grid and Flexbox
- Dark/light theme switching
- Skills and experience visualization

Backend:
- Node.js native HTTP server for AI service endpoints
- CORS-enabled REST API for AI functionality
- Environment variable configuration with dotenv

Database & Authentication:
- Supabase (PostgreSQL database) for portfolio data storage
- Supabase Auth for user authentication and session management
- Real-time data synchronization and user state management

AI Integration:
- Gemini API for AI-powered content generation
- Fallback heuristic algorithms for content suggestions

PDF Generation:
- jsPDF library for PDF document generation
- jsPDF-autotable plugin for structured table layouts
- Template-specific PDF formatting matching visual designs

Development Tools:
- Git version control
- Package management with npm
- Modular JavaScript architecture

4. UNIQUE SELLING POINT (USP)
------------------------------
DevEngine's primary USP is its combination of AI-powered content generation with template-specific PDF export functionality. Unlike generic portfolio builders, DevEngine:

1. **AI-Enhanced Content**: Automatically generates professional project descriptions and summaries using the Gemini API, reducing the time users spend writing content.

2. **Template-Specific PDF Export**: Generates PDFs that exactly match the visual design of selected templates (Flight Attendant, Legal Assistant, Office Manager), ensuring brand consistency across web and print formats.

3. **Industry-Specific Templates**: Provides purpose-built templates for different industries with appropriate color schemes, layouts, and content structures.

4. **GitHub Integration**: Seamlessly imports user profiles and repositories from GitHub, automatically populating portfolio data.

5. **Real-Time Preview**: Offers instant visual feedback during portfolio creation with live preview functionality.

6. **Multi-Format Export**: Supports both CSV and PDF exports, enabling users to share their portfolio data in various formats for different use cases.

The platform addresses the common pain point of portfolio creation by combining intelligent content assistance with professional design templates, making it accessible to developers who may lack design expertise while ensuring high-quality, industry-appropriate output.
