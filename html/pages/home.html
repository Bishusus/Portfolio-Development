Got Questions?

Frequently Asked Questions

How does GitHub import work? +

Simply enter your GitHub handle on the builder page or hero section. We query the official GitHub REST API to safely retrieve public repositories, your bio, primary languages, and recent project updates without requiring access tokens or passwords.

Can I edit my portfolio after publishing? +

Yes! You can edit, re-sync GitHub projects, or switch templates anytime in the builder and re-publish updates directly to your live portfolio link.

Can I export my portfolio data? +

Yes! You can export your portfolio as PDF with template-specific formatting or as CSV for data portability and backup purposes.
